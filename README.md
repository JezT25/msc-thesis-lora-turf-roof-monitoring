# University of Iceland MSc Thesis — Overleaf Finalization Project

This folder is prepared as an Overleaf-ready LaTeX project using the supplied UoI MSc thesis template and the current thesis materials. The supplied HÍ banner is included in `figs/banner.png`.

## Upload to Overleaf
1. Download the ZIP containing this folder.
2. In Overleaf choose **New Project → Upload Project**.
3. Upload the ZIP.
4. Set `main.tex` as the main document if Overleaf does not select it automatically.
5. The project uses BibLaTeX/Biber; Overleaf should run the bibliography automatically.

## Main source material integrated
- Current title-page/template structure from `MSc.tex`.
- Current methodology from `Methodology.docx`.
- Current results from `Results and Conclusions - updated.docx`.
- Current turf-house/soil-moisture literature from `Thesis RRL.docx`.
- The supplied banner image.

## Items to finalize before submission
- Add the Icelandic abstract.
- Finalize acknowledgments and author biography.
- Review all figure/table numbering and cross-references, especially source references that originally used placeholders such as `Figure X` or `4.X`.
- Review the methodology statements around the supported number of nodes (the source material contains both a 3-bit hardware ID description and an 8-node system statement).
- Add final hardware schematics, PCB drawings, firmware appendix, raw calibration data, and any remaining deployment figures if required.
- Confirm the final thesis submission month/year, examiner/committee information, and faculty address against HÍ submission requirements.
- Proofread the final English and check all numerical results against the original datasets.

The chapter text is intentionally based on the supplied thesis materials rather than adding outside research. Where the supplied material contained unresolved placeholders, the project removes or replaces them only when the corresponding information is supported elsewhere in the supplied results.
